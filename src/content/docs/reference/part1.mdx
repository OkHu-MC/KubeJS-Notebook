## CurseForgeのインストール
バニラランチャーを使っても問題なく開発ができるが、ライブラリや共に使う工業mod、  
そしてそれらのアドオンのアップデートを管理するのに便利なので使ってもらう  
   
バニラランチャーでやりたいなら自力で頑張ってください
