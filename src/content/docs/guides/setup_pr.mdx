## Prism Launcherについて

本解説サイトでは基本的に **CurseForge** を前提として進めますが、熱狂的なPrismユーザーからの強い推し（宣伝）があったため、インストール手順のみ掲載しておきます。

:::caution[免責事項・注意]
* 筆者はPrismの使い方を詳しく把握していないため、トラブルが発生した場合は**自力で解決**してください。
* Prism Launcherの使い方に詳しい方、ぜひこのページのドキュメントの拡充・引き継ぎプルリクエストをお待ちしております！
* 基本的には**「CurseForgeに十分慣れてから使う」**ことを強く推奨します。
:::

---

## Prism Launcher のインストール手順

1. **Java環境の準備**
   * お使いの動作環境に合わせた **Java 21 / 22 / 24** 等をあらかじめダウンロード・インストールしておきます。
2. **ランチャー本体のダウンロード**
   * [Prism Launcher 公式サイト](https://prismlauncher.org/) にアクセスします。
   * **「Download Now」** をクリックします。
3. **インストーラーの実行**
   * Windowsの場合はポータブル版（zip）またはインストーラー（.exe）等、好みの形式を選択してダウンロードし、画面の指示に従ってインストールを完了させます。

これでインストール作業自体は完了です！
