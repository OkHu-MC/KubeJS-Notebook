## vscodeのインストール

1. [Visual Studio Code 公式ダウンロードページ](https://code.visualstudio.com/) にアクセスします。
2. ページ内の **「Download for ○○」** をクリックします。
3. インストールします。

VSCのインストールや言語設定などは他のサイトで調べて頑張ってください

## ProbeJSのインストール

[ProbeJS](https://www.curseforge.com/minecraft/mc-mods/probejs)を使用します。　　
KubeJSでのレシピ改変や統合開発において、便利な拡張機能です。  
ちなみに、作者はこのwikiのこのページを作るまで、約1年こいつを使わずに開発していました。  
つまり、最悪なくてもコピペして作るだけなら要りません。  

特にエディタの汎用補完で適当にアプリ開発やるのが好きな人ならあんまり気にならないかもしれません
(あとgithub copilotに制御吸われます)

一旦普段のmodと同じようにインストール

## ProbeJSによる型情報のdump

こいつは、jsから見たMinecraft環境の情報をまとめたdumpファイルを作り  
vscodeを制御する…というもの(多分この説明で合ってるはず)  

1. Minecraftを起動する
2. コマンドを実行する
```txt
/probejs dump
```
3. kubejs/probeが生成されるので、
vscodeの「フォルダを開く」でkubejsフォルダを開く

4. 以上、好きなように開発してください
